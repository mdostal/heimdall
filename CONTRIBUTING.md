# Contributing to Heimdall

Welcome to Heimdall! We appreciate your interest in contributing to the Pantheon ecosystem.

## How to Contribute
1. **Reporting Bugs:** Use the GitHub Issues tab to report bugs. Please include steps to reproduce and relevant logs.
2. **Suggesting Enhancements:** We welcome ideas! Open an issue describing your proposed enhancement and its use case.
3. **Pull Requests:** 
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/my-feature`).
   - Ensure you follow the project's coding conventions and add tests where appropriate.
   - Run `npm run build` and `npm test` before submitting.
   - Open a Pull Request and describe your changes clearly.

## Development Setup
- Requires Node.js >= 22.5.0.
- Copy `.env.example` to `.env`.
- Run `npm install` and `npm run dev`.

Please read `docs/vision.md` for a deeper dive into the project goals and where you can help out.
